# Shivali Munshi

Portfolio website for [shivalimunshi.com](https://shivalimunshi.com).

## GitHub Pages

Publish from the `main` branch at `/ (root)` in Settings → Pages.
Set the custom domain to `shivalimunshi.com`, then enable HTTPS when the certificate is ready.

## Files

- `index.html`: the complete portfolio
- `media/`: robot demo video and poster
- `CNAME`: custom domain configuration
- `.nojekyll`: serves the website as static files

Update these files on `main` to publish future changes.
